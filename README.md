# Chess

A small, local, two-player chess game built with C# and ASP.NET Core.

## Run

Install the .NET 11 SDK, then run this folder:

```powershell
dotnet run
```

Open the local URL printed by ASP.NET Core. The game supports legal moves, check, checkmate, stalemate, castling, en passant, automatic queen promotion, and the fifty-move draw rule. Game state is kept in the running server process.
